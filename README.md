# Text DNA Analyzer 🧬

A Python-based text analysis application built with Streamlit.

## Features

- Word and character counting
- Word frequency analysis
- Unique word and vocabulary analysis
- Longest and shortest words
- Average word length
- Punctuation and letter analysis
- Basic keyword-based sentiment analysis
- Interactive statistics and charts

## Technologies Used

- Python
- Streamlit
- Pandas

## Installation

1. Clone or download this repository.
2. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

3. Run the Streamlit application:

   ```bash
   streamlit run text_analyser_streamlit.py
   ```
